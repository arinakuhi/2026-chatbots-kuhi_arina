# Lab 3 — Telegram Bot Deployment

В рамках третьей лабораторной работы Telegram-бот Task Assistant Bot был развернут в облачной среде Railway.

## Функционал

Бот позволяет управлять персональными задачами.

Доступные команды:

- `/start` — запустить бота
- `/help` — показать список доступных команд
- `/add <priority> <task>` — добавить новую задачу
- `/tasks` — показать все задачи
- `/active` — показать только активные задачи
- `/done <number>` — отметить задачу выполненной
- `/delete <number>` — удалить задачу
- `/stats` — показать статистику задач

## Хранение данных

Для хранения задач используется база данных SQLite.

Каждая задача содержит:

- идентификатор пользователя;
- текст задачи;
- приоритет;
- статус выполнения;
- дату создания.

## Улучшение в Lab 3

После пользовательского тестирования была добавлена новая команда:

`/active`

3. низкий.
